# Local rules — cards

Rules that are true for this repo and are not fleet canon. The fleet constitution's core lives in `../../AGENTS.md` inside the `FLEET-CANON` block and is never edited here; the rest of it is in `../fleet/docs/skills/coordinator.md` and `../fleet/docs/work-rules.md`.

Each line below is one rule, linked to the file that holds it in full with what it was learned from; open that file when the work reaches the rule.

- [The engine reports what reached a target; the view decides what is worth saying](rules/engine-reports-view-decides.md)
- [A change to a screen re-runs every probe that navigates to it](rules/screen-change-reruns-probes.md)
- [A saved log is a list of indices into offers, so content retires it, not just format](rules/saved-log-retired-by-content.md)
- [Every input to the draft is in the log, or the log is a different run wearing its seed](rules/draft-inputs-in-the-log.md)
- [A mutation runner's red is attributed to a failing line, and differenced against a measured green baseline](rules/mutation-runner-red.md)
- [A gate whose subject is a list reads that list; it never restates it](rules/list-gate-reads-its-list.md)
- [A sentence about what a gate catches is written from that gate's code](rules/gate-claims-from-gate-code.md)
